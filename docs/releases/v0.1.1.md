# v0.1.1 verification — 2026-10-22

## Browser foundation

`npm run test:browser`: **8 passed** in 17.4 seconds on Windows with Playwright 1.64.1 / Chromium 156. Every test gets a fresh local server and its own sessions. Two-person workflows use separate browser contexts and real WebSockets. No running personal chat session is reused.

| Workflow | Verified behavior |
| --- | --- |
| Room chat, IMs and away replies | Create/join a member room, identify the host, exchange room messages, open a receiving IM window and show the away reply |
| HTML injection | Room and IM payloads remain literal text; no injected image/SVG or unexpected dialog |
| Ignore/unignore | Room text and IM windows suppressed, delivery restored after unignore |
| Art picker | Catalog loads, complete skull reaches both people, exact leading spaces survive and rendered lines use `white-space: pre` |
| Stop | Partial scroll stops while the other person completes a fresh full scroll |
| Room change | Departure cancels pending art; subsequent old-room traffic never reaches the new room |
| Buddy/session lifetime | Presence follows sign-on/off; sign-off removes chat windows; signing back on starts with an empty buddy list |
| Narrow layout and keyboard | Keyboard sign-on, slash-command picker, divider printing and Roll Up work at 420 × 760 with no horizontal overflow |

`npm run test:browser:controls`: **2 deliberately broken browser implementations detected** by assertion failures. Controls replace safe text rendering with `innerHTML` and disable the Stop button in isolated copies. Browser startup failures do not count as successful detection. The eight tests have no automatic retries and also fail on script/console errors or unexpected dialogs.

Windows and Ubuntu browser jobs run on pushes and pull requests. They install the locked Playwright browser, run the suite and controls, and keep reports plus failure traces/screenshots/videos as downloadable artifacts for seven days. [CI runs](https://github.com/pnmcguire480/almost-online/actions/workflows/ci.yml) · [Harness and recording guide](../BROWSER_TESTS.md)

## Demo evidence

The demo script drives a real app server and two isolated Chromium participants. The 43.2-second recording shows sign-on, room chat, setting an away message, an incoming IM, online buddy presence, skull/banner scrolling, the tribute picker, Stop and a collaboration invitation. It captures only the app viewport.

Rendered MP4: **1440 × 810**, **25 fps**, H.264 / yuv420p, AAC mono, approximately **1.07 MB**. Scene captions are burned in; SRT captions and the silent raw WebM are also published. Original synthesized tones were added during rendering; desktop/microphone/app audio was not captured. No personal tabs, original executables or historical recordings were used.
