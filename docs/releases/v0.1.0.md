# v0.1.0 verification — 2026-10-22

Local run: Windows, Node.js 24.14.0. This release is a local application and a public collaboration foundation.

## Automated evidence

- `npm run test:coverage`: **95 passed, 0 failed**; **95.86% server lines**. The command enforces a 90% line floor over `server.js` and `lib/**/*.js`. Browser JavaScript is outside this metric. `security.js`, `static.js`, `art.js`, `incidents.js`, configuration and rate limiting have 100% line coverage.
- `npm run test:controls`: **8 broken controls detected** in isolated copies: missing cancellation, ignored-user filtering, ASCII whitespace, timing, origin validation, canonical path checking, output backpressure and connection limits.
- `npm audit --json`: **0 known advisories**, including development dependencies, at release review time.

The earlier 87-test result and 95.50% figure remain in [VERIFICATION.md](../VERIFICATION.md) under their original criteria.

## Red-team cases and fixes

| Attack or failure | Verified result |
| --- | --- |
| Hostile website opens local WebSocket | Untrusted, null, mismatched-port and HTTPS origins rejected with 403; matching HTTP origin and non-browser clients still connect |
| DNS rebinding Host alias | HTTP and WebSocket requests rejected with 403; host suffix tricks and wrong ports rejected |
| Duplicate or absent Host | Rejected by the Host boundary |
| Static junction points outside public | Private canary remains unreadable, including encoded link names; internal links still work |
| Path traversal, hidden files, alternate streams | Rejected without serving file content |
| More than 128 WebSocket clients | Next upgrade rejected with 429; a freed slot can be reused |
| Fragmented frame exceeds 4 KiB | Offender closed with 1009; a new healthy client signs on afterward |
| Client stops draining output | Queue threshold triggers 1013; disconnect releases session, socket and active art job |
| Ignore/report retention growth | Ignore cap preserves existing entries and supports remove/re-add; newest 500 reports retained with only name/time |

Existing tests exercise room isolation, host-only kick, case-insensitive name ownership, ignore for room messages and IMs, session reset, inbound throttling, idle expiry and every scroller cancellation path. Resource ceilings bound retained work; they do not authenticate local programs or guarantee availability against a process with local machine access.
