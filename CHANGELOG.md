# Changelog

## 0.1.1 — 2026-10-22

Added eight real Chromium workflows with fresh servers and isolated browser participants, two deliberately broken browser controls, and Windows/Linux browser CI on pushes and pull requests. Failed runs retain screenshots, traces and participant videos for seven days.

Added a reproducible screen recorder and MP4 renderer with captions and original synthesized tones. The demo and captions are published as release assets. [Browser testing guide](docs/BROWSER_TESTS.md) · [Verification](docs/releases/v0.1.1.md).

## 0.1.0 — 2026-10-22

Initial public Almost Online release: local WebSocket chat, AOL-era parody desktop, member rooms, IMs, buddy presence, away replies, profiles, ignore/report controls and a Fate X 3.0 tribute ASCII scroller.

Added strict local Host and browser-origin checks, canonical static-file boundaries, security headers and resource budgets. Verified with 95 tests, eight deliberately broken controls, a dependency audit and a two-tab browser workflow. [Detailed verification](docs/releases/v0.1.0.md).

MIT licensed with contribution guidance, asset provenance and a roadmap toward a collaboratively designed connected edition.
