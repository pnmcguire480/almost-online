# Credits and provenance

Almost Online is a new, independent project by Patrick McGuire and contributors. The code and newly created project assets are distributed under the MIT license in this repository. Dependency licenses remain with their packages.

**America Online / AOL** inspired the desktop and chat-room atmosphere. **Fate X 3.0 by MaGuS & FuNGii** inspired the tribute control panel. These names identify historical inspirations; the original companies and authors are not affiliated with this project and have not endorsed it. The MIT license does not grant rights to third-party trademarks or historical software.

- `public/almost-online.png`: AI-generated Almost Online parody logo, created for this project with OpenAI image generation. The altered wordmark reads A0L / Almost Online.
- `public/icons.svg` and `public/favicon.svg`: newly drawn SVGs in source.
- `public/style.css` and the window layout: newly written CSS and JavaScript, guided by period interfaces and the [preserved Fate X screenshot](https://plozee.com/wp-content/uploads/2024/12/Fate-X-3.0.webp).
- `lib/art.js`: newly supplied ASCII drawings and banner for this implementation. No original art pack is distributed.
- Sound effects: synthesized by the browser; no original AOL sound recordings are bundled.
- `docs/screenshots/`: captures of this project. Older captures may show earlier branding and attribution text.

Development used AI coding assistance. [Historical sources](docs/HISTORY.md) are references, not bundled binaries. No historical executable is included or required.
